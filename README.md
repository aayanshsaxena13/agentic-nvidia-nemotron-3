# agentic-nvidia-nemotron-3
Steps to setup your agentic developer environment are:
1. Install Python 3
2. Install OpenRouter SDK
3. Install Python 'eel' package
4. Get OpenRouter API key.
5. Create a '.env' file
6. Set "API_KEY" environment variable as the api key you got
