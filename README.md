# agentic-nvidia-nemotron-3
🤖 This repositery contains a Jupyter Notebook. 🧑‍💻 If you run it inside VSCode, Cursor, or Jupyter, it could automate tasks for you with assistance of Nvidia Neumotron 3 from OpenRouter.
___________________________________________________________________________________________________________________
# Prerequisites
=> IDE: ideal would be VSCode<br>
=> API Key: from OpenRouter<br>
=> Python on your computer
___________________________________________________________________________________________________________________
# Instructions
=> Create a ".env" file in project root and put API_KEY=as the API key you generated<br>
=> Open Jupyter Notebook and run the code inside your IDE and inside the project root.
